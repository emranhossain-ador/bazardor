# 🛒 বাজার দর (BazarDor)

### Short Description
BazarDor is a Bangla-language web application that helps users check daily prices of essential grocery products in Bangladesh. Users can explore product categories and make smarter shopping decisions.

### 🛠️ Technologies Used
- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- Better Auth
- MongoDB
- REST API

### ✨ 5 Key Features
1. **Daily Market Prices:** View daily prices of essential grocery products.
2. **Price Change Tracking:** Check which products have increased or decreased in price.
3. **Product Categories:** Browse products by different categories.
4. **Dynamic Product Details:** View individual product prices and market information.
5. **User Authentication:** Register and log in to access protected pages.
